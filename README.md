# ffs

Continuous vulnerability intelligence for Kubernetes.

ffs runs inside your cluster. It inventories what is running, re-matches that inventory against new advisories within minutes, ranks findings by exposure, suggests the nearest fixing upgrade, and reports through CRDs, Events, Slack, Discord, Teams and generic webhooks, OpenReports, and metrics.

Status: in development; the first release will be v0.0.1.
